# LOTTOVIP

LOTTOVIP is a mobile-first lottery experience simulator created for UX/UI, full-stack, database, security, ledger, and payment-sandbox learning.

> Demo / Simulation only — credits have no cash value and cannot be exchanged or withdrawn as real money.

## Project status

- Phase 0: UX/UI prototype
- Primary documents: PRD v2.1 and UX/UI Blueprint
- Planned prototype screens: Login, Dashboard, Round Catalog, Number Entry, and Receipt

## Development workflow

- `main`: stable project baseline
- `agent/*`: development branches
- Changes are reviewed through Draft Pull Requests before merging
